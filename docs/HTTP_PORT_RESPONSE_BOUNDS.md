# Standalone HTTP response admission

Incomplete WIP, dependent on credential-selection PR46. The shared standalone Evidence/Consent HTTP call now uses one monotonic 100..120000ms budget starting before credential selection, with admission after synchronous credential work, transport, each stream read, decoding and JSON parsing. Responses are limited to 512KiB and 4096 chunks (empty chunks count). A finite advertised content length is checked before reading; actual bytes remain bounded independently. UTF8 is fatal, chunks are copied before retention, and no partial JSON is returned.

An owned AbortController closes on every exit; a timeout race withholds late callback/stream results even when an injected fetch ignores the signal. Late response bodies and incomplete readers receive best-effort cancellation. Cancellation hooks are not awaited: a host implementation may never settle. Native promise rejections are observed and timers/listeners removed. Callback/stream/parser diagnostics are sanitized. The receiving engines still verify signatures; locally decoded token payloads are not authentication.

Six new synthetic regression groups fail against PR46 source and pass after this change, along with four credential-selection groups (10 total, no failures/skips). They cover blocked-JS transport/credential admission, oversized advertised/actual bodies without EOF, empty-chunk floods, malformed UTF8, stalled reads and closed/late signals. Typecheck/build/registry, installed exports, source review and final-head CI are separate; qualification is incomplete. No full local PostgreSQL or deployed source/auth/rights claim.

This cannot preempt blocked JavaScript, undo a remote call, terminate a noncooperative callback, or prove remote quiescence. A timed-out Consent decision may have been durably audited upstream: unavailable is not rollback. No replay, retry, publication or execution permit is issued. No SDK/SQL/schema/pin/original architecture ID/dependency changes. Operational PAM stays at its authorized foundation.
