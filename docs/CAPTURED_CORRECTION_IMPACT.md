# Captured Knowledge correction impact (incomplete)

`./correction-impact` exports `inspectCapturedKnowledgeCorrectionImpact(context, knowledgeJson, before, after)`. This pure private profile computes dependency metadata over EVERY captured Knowledge record and claim edition, including claims that no investigation plan references. It complements Factual's all-plan impact view; it does not replace it.

The exact scoped positive before/after pair must be consecutive actual predecessor/successor editions, with the successor latest in the capture. The actual owning `inspectKnowledge` validator admits the whole private history (2048 records/2MiB), host research context, chronological typed references and null independent assessment dimensions. Mixed-purpose histories, absent dependencies, malformed lineage and stale correction pairs fail the whole report. History snapshots and Context are trusted host input, not proofing, current Identity/Consent/Evidence or authentication of past actors.

Every historical edition retains its original children. Exact claim-subject, event-entity and relationship-from/to edges are recorded once. Reverse traversal starts at ALL observed older editions of the corrected logical record and visits each dependent node once. All claim editions remain explicit, with a separately latest observed claim. Successor-only and unrelated captured graphs are not relabelled merely because the logical subject changed. `no-captured-dependency` means only that the admitted captured graph contains no path to an older corrected edition; it is NOT permission, usability, verified truth or proof of no real-world impact.

Input is bounded to5MiB UTF8 before parsing, the owning validator preserves its2MiB/2048 limits, graph edges to8192 and complete output to512KiB. Failure returns no truncated graph or partial claim list. The result is detached private metadata; no source values are rewritten, commands stored, decisions invalidated or findings/closure/approval promoted. Evidence links, verification reviews, current source permissions, investigation plans, findings, draft outputs and raw audit events are explicitly unloaded. No fabricated storage/audit references, current time or actors are introduced.

Expanded qualification: ALL8 focused LOCAL and ALL8 packed compiled-public-export groups pass0fail0skip, strict declarations compile and the installed correction-impact runtime byte-matches. Six domain/ref/purpose/history/copy/input groups plus actual valid owning-history8192edge and512KiB whole-output rejection cases are qualified. The packed consumer copies/hardlinks normally prepared dependencies; it is not a fresh install or full installed suite. Full local/current-head CI remain pending. Source review is clear for pure bounded metadata with no effects/current authority; remaining work is explicit. This is explicit WIP partial AM-05-08, not full original dependency acceptance. Owning checked SQL/current Identity/ALL-source consent interfaces, protected HTTP/Visual projection, findings/draft impact, full workflow/Editorial/closure and host/browser/AT/live qualification remain separate. No new pins/contracts/schema/original design IDs or dependencies; only a new package export. No sends, publication, payment, paid infrastructure or operational PAM.
